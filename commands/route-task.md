# route-task

1. Read project-local `AGENTS.md`.
2. Identify the authoritative task or SPEC.
3. Inspect the relevant repository surface.
4. Assess scope, affected layers, reversibility, validation quality, and security/data/migration risk.
5. Choose one tier: `economy`, `standard`, `strong`, or `premium`.
6. If too large for one coherent unit, route to `split-spec`.
